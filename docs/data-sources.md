# Data sources

Status legend: **verified** = checked with a real call (date, UTC); **unverified** = implemented from the
documented/observed format and still to be confirmed with `windows/tools/KitBuilder.EndpointProbe`.

Recorded responses used by the tests live in `shared/test-fixtures/recorded/` (real) and
`shared/test-fixtures/samples/` (synthetic, to be replaced by recordings).

## 1. Item catalog — ByMykel/CSGO-API (MIT) — verified 2026-11-06

- Base: `https://raw.githubusercontent.com/ByMykel/CSGO-API/main/public/api/<locale>/`
- Files: `skins_not_grouped.json` (~32 MB, 21,407 entries), `skins.json` (2,126 skins, used by the color
  pipeline), `stickers.json`, `keychains.json`, `collections.json` (all HTTP 200).
- **No `pt-BR` folder** (`pt-BR/skins_not_grouped.json` → 404). The app tries `pt-BR` then falls back to `en`.
- Conditional requests: GitHub raw returns `ETag` (strong for the big files, weak `W/"…"` for others) and
  `Cache-Control: max-age=300`; no `Last-Modified`. The app sends `If-None-Match` at most once a day.
- `skins_not_grouped.json` entry (shortened):
  ```json
  {"id":"skin-e757fd7191f9_0","skin_id":"skin-e757fd7191f9","name":"★ Hand Wraps | Spruce DDPAT (Factory New)",
   "weapon":{"id":"leather_handwraps","name":"Hand Wraps"},"category":{"name":"Gloves"},
   "pattern":{"name":"Spruce DDPAT"},"min_float":0.06,"max_float":0.8,"wear":{"name":"Factory New"},
   "stattrak":false,"souvenir":false,"rarity":{"name":"Extraordinary","color":"#eb4b4b"},
   "market_hash_name":"★ Hand Wraps | Spruce DDPAT (Factory New)","team":{"id":"both"},
   "image":"https://community.akamai.steamstatic.com/economy/image/…"}
  ```
- Facts used by the code:
  - Every `skin_id` exists in `skins.json` (0 orphans) → the color index is keyed by `skin_id`.
  - Doppler/Gamma Doppler phases are separate skins with a `phase` field, but **share the same
    `market_hash_name`** (122 duplicates). Steam therefore has a single price for all phases: the
    lowest listing, which belongs to a common phase. Gem phases (Ruby, Sapphire, Black Pearl,
    Emerald — 4 to 7 times more expensive) are not offered as market candidates (issue #1);
    Phase 1–4 use the shared price.
  - Vanilla knives have no `wear` (e.g. `★ Bayonet`).
  - Categories: Rifles (snipers included), Pistols, SMGs, Heavy, Knives, Gloves, Equipment (Zeus x27).
  - `team.id`: `both`, `counter-terrorists`, `terrorists`.
  - Rarity colors match the design tokens (`Mil-Spec Grade` is the catalog name).
- Images: `community.akamai.steamstatic.com/economy/image/<hash>`; append `/256fx256f` for a 256 px PNG
  with transparent background (verified).

## 2. Color index — generated by `/data-pipeline` — verified 2026-11-06

`python data-pipeline/build_color_index.py --out color-index.json` processes all 2,126 skins in ~30 s
(images cached), output ~1 MB. Published weekly as a release asset (`data-YYYYMMDD`, workflow
`data-index.yml`). Schema:

```json
{"schemaVersion":1,"generatedAt":"…","colorSpace":"OKLab","count":2126,"skins":[
  {"skinId":"skin-…","name":"AK-47 | Redline","phase":null,
   "colors":[{"hex":"#22201e","l":0.2418,"a":0.0021,"b":0.0049,"weight":0.7515}, …],
   "meanLightness":0.27,"meanChroma":0.02,"meanHue":57.4,"isMultiColor":false}]}
```

Method: opaque pixels only (alpha ≥ 200), OKLab, neutral pixels (chroma < 0.04) and colored pixels are
clustered separately (k-means++, fixed seed) so small accents survive (Redline's stripes ≈ 4.5 %),
clusters closer than ΔE 0.04 merged, shares < 3 % dropped. `isMultiColor`: finish name (Fade, Doppler,
Case Hardened, Marble Fade, …) or colored clusters ≥ 90° apart in hue.

## 3. Prices — Steam Community Market

### 3.1 Bulk: `/market/search/render/` — verified 2026-11-06

```
https://steamcommunity.com/market/search/render/?appid=730&norender=1&count=10&sort_column=name&sort_dir=asc
  &category_730_Type[]=tag_CSGO_Type_Pistol&…&category_730_Type[]=tag_CSGO_Type_Knife&category_730_Type[]=tag_Type_Hands&start=0
```

- **Maximum 10 rows per page**: `count=100` still returns `pagesize: 10`.
- **`currency` is ignored** for anonymous requests: from a US IP `sell_price_text` is `"$11.51"` and
  `sell_price` is USD cents. The parser reads the currency from `sell_price_text` (R$ or $) — if Steam
  answers in BRL from a Brazilian IP, no conversion happens.
- Weapons + knives + gloves: `total_count` 15,770 → ~1,580 pages. With 3.5 s between requests a full
  refresh takes ~1.5 h, so it runs incrementally in the background and resumes where it stopped
  (cursor stored in SQLite).
- Row: `{"hash_name":"AK-47 | Aphrodite (Battle-Scarred)","sell_listings":634,"sell_price":1151,
  "sell_price_text":"$11.51","sale_price_text":"$11.08","asset_description":{…}}`. Rows with
  `sell_price: 0` have no listing and are skipped.

### 3.2 Single item: `/market/priceoverview/` — verified 2026-11-06

`?appid=730&currency=7&market_hash_name=<urlencoded>` →
`{"success":true,"lowest_price":"R$ 177,68","volume":"56","median_price":"R$ 864,95"}`.
`currency=1` gives `"$32.63"` / `"$158.90"`. Strings use the currency's own separators.

### 3.3 USD → BRL conversion

The rate is derived from Steam itself: median of (BRL ÷ USD) over liquid reference items from
`priceoverview` (median price preferred, lowest as fallback), cached 24 h. Observed 2026-11-06: **5.443**.

### 3.4 Rate limits (observed 2026-11-06)

- About 5 quick requests in a row triggered **HTTP 429** on both endpoints; the block on that IP lasted
  between 15 and ~60 minutes. Cloud/datacenter IPs are blocked more often than home connections.
- The app: one request at a time to steamcommunity.com, ≥ 3.5 s apart, exponential backoff on 429
  (30 s doubling to 10 min, honoring `Retry-After`), SQLite cache with a 6 h TTL, stale prices flagged.

## 4. Inventory — `/inventory/{steamid64}/730/2` — verified 2026-11-12

```
https://steamcommunity.com/inventory/{steamid64}/730/2?l=english&count=2000[&start_assetid=<last_assetid>]
```

Verified with a real public inventory (HTTP 200, 22 items; sanitized excerpt in
`shared/test-fixtures/recorded/steam-inventory.sanitized.2026-11-12.json`, identifiers replaced).

- Top-level fields: `assets`, `descriptions`, `asset_properties`, `total_inventory_count`, `success`,
  `rwgrsn`; `more_items`/`last_assetid` only when there is another page. Assets and descriptions are
  joined on `classid`+`instanceid`.
- **Float / pattern are available** in `asset_properties` per asset: `propertyid` 1 "Pattern Template"
  (`int_value`), 2 "Wear Rating" (`float_value`, full precision), 6 "Item Certificate"
  (`string_value`, hex). Only painted weapons have 1 and 2; most items have 6.
- **Inspect links** (`actions[].link`) no longer use `%owner_steamid%`/`%assetid%`:
  `steam://run/730//+csgo_econ_action_preview%20%propid:6%` (placeholder filled from property 6) or
  `…preview%20<hex payload>` (complete). `%propid:N%` handling: issue #7.
- Stickers: `sticker_info` HTML block, one `<img … title="Sticker: <name>">` per sticker followed by
  `Sticker: <name>, <name>`. Charms: `keychain_info` block (not present in the verified inventory).
- **Trade protection:** `total_inventory_count` (28) was larger than the returned assets (22). The owner
  confirmed the 6 missing items were received in a trade less than 7 days earlier; trade-protected
  items are hidden from the public inventory for 7 days. `/inventory/{id}/730/16` returned no assets.
- 403 / `null` body → "inventory is private" screen. One full load per profile every 10 minutes
  (configurable), cached in SQLite.

## 5. Profile resolution — `/profiles/<id>` verified 2026-11-12; vanity **unverified**

SteamID64 or `/profiles/<id>` are used directly. Vanity names (`/id/<name>`) are resolved without an
API key through `https://steamcommunity.com/id/<name>/?xml=1` → `<steamID64>…</steamID64>`.

## How to verify / update

```bash
dotnet run --project windows/tools/KitBuilder.EndpointProbe -- --steam-id <your profile URL>
```

It waits 4 s between calls, writes the raw answers to `./probe-output/` (ignored by git — the inventory
is personal data) and a `summary.md` without inventory contents. Update this document and the recorded
fixtures from it.
